## 04 四层与短按、按住

| 层 | 怎么进入 | 怎么退出 / 何时结束 |
| --- | --- | --- |
| 0 普通层 | 开机默认、层返回操作 | 日常字母与鼠标 |
| 1 SYM | 点一下 SYM；或按住；普通层双击 $ 可固定进入 | 一次性用下一次键码或约 3 秒超时；固定层按 SYM 回普通 |
| 2 aA / UPPER | 短点右 aA 一次性；按住临时滚动；快双击锁轮并固定；快捷键见第6章 | 一次性到下一键/3秒，临时持有松开结束；固定层不被旧计时撤销，SYM 退层但不解锁轮 |
| 3 MEDIA / 原默认留空层 | 按住 SYM 后快双击 $，再松开 SYM | $ / SYM / 右下 aA 三个出口回普通层；其余39位置无绑定输出 |

**一次性层：** 点一下、松开层键，再按目标键；适合单个数字、符号、方向。新按下的修饰键也可能消耗一次性层，因此组合操作先按修饰键，再进层。

**临时层：** 按住层键再操作，适合连续输入；层键是 hold-preferred，期间按其他键可提前确认为按住，不必故意等满 450ms。

| 行为 | 当前时间参数 |
| --- | --- |
| SYM、右 aA、普通层左 Ctrl 的短按 / 按住 | 450ms |
| 返回 / 结束通话、SYM 的 T / Y 长短按 | 默认 mod-tap 约 200ms；按键交叠也影响裁决 |
| 一次性层未用超时 | 3000ms |
| 左 Ctrl 一次性修饰未用超时 | SDK 默认约 1000ms |
| $ 的 tap-dance / aA 层触板 tap-dance | 400ms；不是轻拍点击间隔 |

aA 的临时、一次性、固定持有分别仲裁：双击后旧一次性层3秒超时/迟到释放只清自己的持有，不撤销固定 UPPER。SYM 可退层但不清滚轮锁定；重入 aA 后双击解锁，解锁仍留 UPPER。

## 05 左肩、右肩与机械点击

**普通层：** 默认左肩为左键、右肩为右键，触板机械按压固定为左键。启用鼠标翻转模式后，两侧肩键的左右键角色互换，但触板机械左键不变；该模式只影响普通鼠标，SYM / UPPER / MEDIA 的其他层绑定不变。机械点击与轻拍算法互不等同；关闭轻拍后仍可正常用机械鼠标键。

| 当前承载左键角色的肩键动作 | 结果 |
| --- | --- |
| 单击 | 普通左键单击；为等待可能的三击，可能稍后输出 |
| 双击 | 保留两次左键，双击效果由主机判断 |
| 按住并移动触板 | 左键拖动；移动时提交按下，不继续等三击 |
| 快速完整三击 | 切换轻拍 ON / OFF；这三下被开关消费，不额外发三次鼠标点击 |

**三击做法：** 回普通层，对当前映射为左键的肩键连续按下并松开三次（默认左肩；翻转模式下是右肩）；不滑触板、不夹其他键。每拍按住不超过 180ms，两拍之间从上次松开到下次按下不超过 220ms。

**为什么左键肩键单击可能略慢？** 若没有继续点击，待第三拍识别窗口结束才回放单 / 双击；按住超过 180ms、出现移动或其他键可结束识别并交回普通鼠标操作。原始事件顺序保留，但不是“零延迟”。

切层、切主机、连接变化会取消不该跨上下文发送的待处理序列。不要在切槽或切层途中做三击。

轻拍开关只在普通层当前承载左键角色的肩键上触发；SYM 肩键是音量加/减，UPPER 肩键是滚轮上/下，MEDIA 两肩为显式无输出。不要在这些层用三击尝试开关。

MEDIA 的触板机械按压绑定为 `&none`，不发鼠标左键；其余普通键位同样不会透明回落。但键位无输出不等于关闭触板传感器或驱动物理监听；正常点击请先从三个出口回普通层。

## 06 指针、拖动与滚轮

鼠标路径保留逐轴一计数防抖：±1往返抑制，持续细移首帧后续发；起步/反向有死区，空闲>50ms清余量，无惯性/尾巴。四慢帧后只削一次突刺，故意快起也可能被削；RAW轻拍影子和滚轮不走该滤波。

**UPPER Z/P28循环：0.6 → 0.9 → 1.2 → 1.5 → 1.8 → 0.6。** 首次1.2，第一次Z到1.5；松开再按才进一档。保持右aA+Z选，物理左下Ctrl减半；普通层Z仍输入字母，MEDIA Z恢复无绑定输出。软件增益/保存详第16章。

BLE仍只合并已积压的≤10ms同向直线XY，不另等候，不跨按键/零帧/滚轮。主机仍可加速，不承诺绝对线性；[防抖取舍](<pointer_steady.md>)。

### 临时滚动与锁定滚轮

| 目的 | 操作 |
| --- | --- |
| 锁轮 / 回正 | 右aA双击固定UPPER，默认0°；再双击解锁，重锁回正（每拍<450ms、间隔≤350ms） |
| P3 黑莓固定档 | 松aA且锁轮，三击：左→上、右→下、上→右、下→左 |
| P5 顶部返回固定档 | 松aA且锁轮，三击：右→上、左→下、上→左、下→右 |
| 蓝牙槽 | 按住右aA，P3/P5立即选槽1/2，锁轮亦优先；未按aA且未锁轮保留槽动作，不选方向档 |
| 鼠标翻转 | 按住右aA双击M/P34切换，180/220ms；夹其他键取消；M未成组合无输出；F/P20在UPPER无输出 |
| 肩键 / 临时恢复 | 锁轮肩键半速且屏蔽自身Wheel；按住aA临时原方向/原生肩轮，松开恢复所选固定档 |

**固定不累加：** 第三次松开选目标档；同键重复不变，换键直接切档。每拍按住≤180ms、松开至下拍≤220ms；其他键取消序列，其余点按吞掉。

SYM退UPPER但不解锁轮；重启锁轮/鼠标翻转关闭。鼠标翻转仅普通指针Y和DEFAULT肩键角色，X/滚轮及其他层绑定不变；Wheel/AC Pan曲线、半速余量/P37减速不变，不必清配对或改主机设置。

## 07 轻拍：可选的运动启发式

**开机默认 OFF。** 在普通层对当前承载鼠标左键角色的肩键快速三击开 / 关；默认是物理左肩，鼠标翻转模式下变为物理右肩。开关不持久保存，重启后要重新开启。没有专属 ON / OFF 灯态：不要把 USB 呼吸、滚轮呼吸当成轻拍开关指示。

本轮仅移除手柄独占与相关发送门，轻拍原资格、时序、开关和必要释放保护不调优。MEDIA 的 `&none` 不自动关闭传感器路径或轻拍状态；普通层以外的绑定与原生保护仍各自生效。鼠标翻转不修改轻拍资格，只让逻辑左键肩键及开关跟随新角色位置。

建议先开启、松开所有键，等约 1 秒再试。做一次短促轻拍，然后自然停下；不要为“更容易触发”持续用力搓动。

| 当前资格条件 | 数值 / 含义 |
| --- | --- |
| 推算净指针位移 | 3–50px（含边界），RAW经所选档/左Ctrl半速的影子增益，不经滤波 |
| 非零运动帧 | 1–8 帧；第九帧转为普通移动 |
| 首末运动跨度 | 不超过 120ms |
| 运动后静止确认 | 至少 120ms 的有效零运动轮询 |
| 自动点击最小间隔 | 至少 300ms；不是主机双击识别上限 |
| 原生机械活动保护 | 持有时阻止自动点击，释放 / 末次活动后再保护约 600ms |

**它不是可靠的触点 / 抬指识别。** 传感器运动满足短、位移合适、随后安静，算法就可能认为是一次点击。因此轻擦、小搓动、短促滑动也可能误点；完全没有运动量的轻触也可能不点。

候选命中时会消费那组运动；不合格时按原始帧回放为指针移动。因此开启后某些小移动可能先被短暂缓冲，不能称零延迟。

300ms 最小间隔允许部分自然双击节奏通过，但主机还要看自己的双击时间、位置等规则。过快两次轻拍可能只得到一次；也不提供双指右键、三指手势或可靠的轻拍拖拽。

## 08 轻拍时间与滑动后迟滞

**三个“等一下”分开理解，不能把数值简单相加。** 它们在不同状态生效，且多项时间并行计算。

| 时间 | 从哪里算 | 作用 |
| --- | --- | --- |
| 120ms 静止确认 | 候选的最后一帧运动 | 观察短促运动是否真的停下，不是无线发送后等待 |
| 200ms 普通重武装 | 普通候选 / 自动点击路径的末次运动 | 回弹期间不立刻生成新候选 |
| 300ms 滑动重武装 | 明确超限滑动路径的最后一次运动 | 延长滑动后保持普通指针的时间 |
| 300ms 自动点击间隔 | 前一次自动点击判定 / 输出接受保护 | 太近的自动点击丢弃，不排队补发 |
| 约 600ms 原生保护 | 原生机械 / 当前左键角色肩键活动与释放 | 避免紧跟机械点击再自动补一次 |

### 基线保留的滑动后迟滞，能挡什么

运动超过 50px 屏幕推算范围、跨度超过 120ms、超过帧数等上限后，进入较长的滑动通道。此后要**连续静止满 300ms**才重新识别轻拍；期间哪怕只轻轻挪一下，也按普通移动输出并重新计时。

### 它不能挡什么

刚开始的小搓动若始终落在 3–50px、1–8 帧、120ms 内，又静止 120ms，仍可能直接满足轻拍条件，根本没进入“明确滑动”通道。**延长滑后迟滞不是消除所有小范围误点的保证。**

静止必须来自有效传感器轮询；断流、读错、无数据不能假装抬指。太旧候选、时钟异常或上下文变化会取消，不会补发迟到点击。已经发出的自动点击也不能被未来的机械点击撤回。

## 09 Cmd、Ctrl、Shift 与多选

### 普通快捷键

普通层先按住黑莓键，再按 C / V / X / Z / A 等，发 Cmd（左 GUI）组合；在 Windows 常对应 Win，安卓及各 App 的行为以主机为准。键盘不会自动把 Cmd 换成 Ctrl。

左下 aA 是 Ctrl：按住可连续组合；点一下松开则是一次性 Ctrl，随后一颗非修饰键使用它，未用约 1 秒超时。Z 左边的 alt 键帽实际是 Shift。

### 右 aA + SYM：双顺序都能 Ctrl

从普通层开始，同时实际按住右 aA 与 SYM，**先 aA 后 SYM、先 SYM 后 aA 都支持**。此时输出左 Ctrl；任意一颗松开就释放这份 Ctrl，保留另一颗再重按也能重新组成。

仅处于一次性/固定 aA 层，或只锁定滚轮但右 aA 已松手，不满足双键 Ctrl；右 aA 已松手时按 SYM 回普通层。MEDIA 不新增这组 Ctrl 组合。

**不要拿它直接做 Ctrl+C / V：** aA 层 C / V 是灯光调节，不是字母；日常字母快捷键用普通层左下 Ctrl。

### Cmd + 鼠标多选 / 拖动

先在普通层按住黑莓 Cmd，再用触板机械左键或左肩；需要范围选择时可先按住 Shift 再点击。主机软件必须支持相应选择方式。

同源菜单 + 点击已有用户正面反馈，但这不等于验证了任意多键无冲突。遇到串键、粘键先松开；不要为证明全键无冲突盲试多颗维护键。

## 12 Shift 扩展与组合输入示例

### 输入 % 或美元符号

1. 在普通层按住 Z 左侧的 alt 键帽（真实 Shift）。
2. 短点 SYM 并松开，Shift 一直保持。
3. 按 D 得 %，按 S 得 $，最后松开 Shift。

也可一直按住 SYM 与 Shift 连续输入。**先点 SYM 再补按 Shift**可能把一次性层消耗掉，最后按 D 就不是数字 5。

### 组合顺序：先修饰键，再进层

| 例子 | 操作顺序 |
| --- | --- |
| Cmd + 1 | 普通层保持黑莓 → 点 SYM 松开 → W |
| Cmd + Shift + 3 | 保持黑莓与 Shift → 点 SYM 松开 → R |

## 14 蓝牙槽与 USB / BLE 输出

### 选择四个蓝牙槽

从普通层按住右 aA，再按通话 / 黑莓 P3 / 顶部物理返回 P5 / 结束，分别选槽 0 / 1 / 2 / 3。空槽可在主机蓝牙设置配对，已配对槽用于切回对应设备；具体广告和重连受主机与槽状态影响。

四个槽不固定对应主机；槽号从0计，P5是槽2（第三槽）。**按住右aA时，即使已锁轮，P3/P5也立即选槽1/2**；仅松aA且锁轮时三击选固定档，其余点按吞掉，见第6章。鼠标翻转现用右aA+M/P34双击；F/P20在UPPER无输出，不占P5。选槽不清槽，勿清配对或全部设置来排错。

### 插线不等于一定向 USB 输出

输出选择由 USB 就绪、当前蓝牙槽连接状态、保存的输出偏好共同决定。选蓝牙槽不等于选 BLE 传输；USB 仍可能是当前输出。

| 要做什么 | 当前入口与注意事项 |
| --- | --- |
| 优先 BLE | 右 aA + Q；这是 OUT_BLE 偏好，不强迫未连上的蓝牙立刻工作 |
| 在 USB / BLE 偏好间切换 | aA 层 $ 快双击；单击项是刷机，谨慎，见第 18 章 |
| USB 键盘 / 鼠标 | 用 USB 数据线连接能枚举 HID 的主机，并确认实际输出端点 |
| 给电脑 USB 充电但用蓝牙 | 是否可行取决于当前就绪和输出偏好，不以“插着线”判断 |

选 BLE 后若活动槽尚未连接，不要误认为按键损坏；先核对槽和主机连接。不要靠清配对来反复试选路。日志串口、充电、USB HID 就绪、BLE 连通是不同状态。

## 15 灯光：两套亮度，分开调

| 想调哪盏 | 调暗 / 调亮 | 开关 |
| --- | --- | --- |
| 键盘背光 | 右 aA + X/P29 减亮、N/P33 增亮 | 右 aA + V/P31 开关 |
| 触控板指示灯 | 右 aA + C/P30 减亮、B/P32 增亮 | 默认未给 BL 单独开关键；可调到 0 |

键盘与触板亮度各自控制，按上表分开调；V/N是键盘开关/加亮，B才是触板加亮。灯光设定**不会改变指针或滚轮速度**。

### 键盘灯表示当前层

| 最高活动层 | 活跃时效果 |
| --- | --- |
| 普通层 0 | 按键授权后常亮；刚启动或空闲恢复不一定立刻亮 |
| SYM 层 1 | 高低亮交替，稳态每约 500ms 换一次 |
| aA 层 2 | 20ms 一步的呼吸变化 |
| MEDIA 层 3 | 慢呼吸：约3.6秒一周期，20ms/1%步进，10→100→10% |

### 触板灯表示当前所选输出与活动

**USB 输出：** 约 1 秒一周期的平滑呼吸，覆盖滚轮动画；不是旧版每秒短闪，也不是电池已充满或轻拍已开启的证明。

**BLE 输出：** 滚轮模式呼吸；普通运动活动时点亮，末次活动后约 5 秒熄灭。此处“活动”来自运动读取，不是可信的手指接触检测。

## 16 亮度与速度记忆、空闲与恢复

### 亮度和指针速度独立保存

五档是固件相对位移增益，非硬件DPI；物理左下aA/Ctrl保持所选档半速（0.3/0.45/0.6/0.75/0.9），一次性/组合Ctrl不触发。切档从下一完整采样帧生效，清旧滤波/小数/轻拍候选，不补旧位移。

键盘和触板各自保存**用户原始亮度设定**，不是保存当前动画那一瞬间的亮度。动画到暗处、空闲熄灯，不会因此把用户亮度写成 0；用户真调到 0 则可以保存。

Z五档另存独立记录，正常重启恢复末次已保存档，首次/坏记录回1.2；不改两盏亮度、配对或轻拍开关。调速/调亮后等至少1秒再断电；快速连调合并保存，中途断电可能仍是上次档位。闪存失败最多试3次，失败时本次只在RAM生效，下一次Z才重试；没有保存成功指示，不保证故障闪存。原v2.3.3曾做模拟重启；本轮待复验，未做设备断电验收。

键盘V开关仍遵循RGB原生状态；触板没有同样的默认开关键，可调到0。**关键盘灯不等于关触板灯。**

### 最低亮度和动画

两路键盘 PWM 与触板 PWM 使用低亮度细分路径，保留小数占空比，载波约 2kHz；USB 触板呼吸以约 20ms 更新。低亮度不是靠软件低频开关灯模拟。

触板末端输出另外压到原比例约 1/3，以降低过亮；这不是测光结果，也不保证与键盘视觉亮度恰好一致。

### 空闲并不等于关机

配置的空闲时间约 30 秒，且本版**系统深睡配置关闭（SLEEP=n）**，不是 30 秒自动关机。键盘四层动画在 idle 都会停止，回普通层通常需一次物理按键重新允许点亮；只滑触板不能保证点亮键盘背光。

触板 USB 呼吸不使用相同的键盘 idle 门控，BLE 普通活动另有约 5 秒熄灯逻辑。不要用某一盏灯判断整机已休眠、主机断开或电池电量；本说明书不承诺未核验的续航、深睡时间或电量百分比。

## 17 MEDIA：原默认与三个出口

**恢复的是原默认绑定，不是凭猜清空。** 来源为 `72c0cee8cb0dbd9e14e692a96d9ef3726bcc73e8` 的两份键图与当时手册，完整42位置、历史行号和逐版本核对见[日用说明](<daily_keymouse.md>)。MEDIA保持层号3；按住SYM，首击按下起400ms内快双击$，再松SYM进入。进入后仍为约3.6秒键盘慢呼吸，不恢复旧快闪。

| 位置 | 绑定与含义 |
| --- | --- |
| $ / P35 | `&to DEFAULT`，切回普通层，不发美元或手柄按钮 |
| SYM / P40 | `&to DEFAULT`，切回普通层 |
| 右下 aA / P41 | `&to DEFAULT`，切回普通层 |

## 18 维护键：确认后再按

以下都指 **aA / UPPER 层**，不是普通字母键。日常打字不需要这些操作。

| 操作 | 实际结果与风险 |
| --- | --- |
| R 按一次 | 重启键盘本体，不是重启电脑 |
| 触板机械单击 | tap-dance 的单击项是鼠标左键 |
| 触板机械快双击 | 清当前选中蓝牙槽配对，不是清所有槽 |
| $ 单击 | 进入 bootloader 刷机引导，正常使用会中断 |
| $ 快双击 | 切 USB / BLE 输出偏好；不够快可能先触发刷机 |
| T 按一次 | 切外设电源，不是主电源，也不是安全的“关灯键” |
| E | 发送 Eject；主机是否处理由系统决定 |

**这里的触板按键是机械按压，不是轻拍算法。** 滚轮模式下轻拍不会替你执行上述 tap-dance；不要把普通层轻拍双击和清配对操作混为一谈。

$、触板 tap-dance 的窗口是 **400ms，从首击按下起算，不是从松开起算**；第二次按下即选择双击项。已超时或被其他键打断时，单击项可能已经执行。按住 $ 到超时也可能进 bootloader，**没有额外长按安全锁**。

切 BLE 优先用 aA + Q。清当前槽仅在确实要重新配对时使用，并准备在主机端处理旧配对记录；不把清配对、settings_reset 或擦整片闪存当成常规排错步骤。

## 19 更新固件与安全回退

### 手动刷写

1. 核对硬件为 **9981 Pro / bbp9981**，固件不能与 Air 或其他型号混用。
2. 保留当前可回退的 UF2 和 SHA-256。先确认有可靠的引导 / 回退路径；本书不猜实体复位键位置，也不要求拆机。
3. 用 USB **数据线**连接能挂载 UF2 磁盘的电脑，再通过已确认的引导入口进入 bootloader。
4. 将核对好的 UF2 复制到出现的刷机磁盘。无需改名，识别依据是内部格式与目标信息。
5. 等复制完成和设备自动重启；磁盘消失常属正常。不要复制中断电或拔线。

蓝牙不会提供 UF2 磁盘。进入 bootloader 不等于已经写入固件；下载完成、构建成功、刷入、实机确认是四个阶段。更新后逐项检查普通键、机械点击、组合键、两套灯，再按需三击开启轻拍。

### 版本与回退

**本轮纯键鼠UF2仍须真实构建与校验后交付。** 功能源为 `bba36b607e0f90401f1840b6a2f897d347f5df52`；真实构建提交、运行号、文件及SHA-256见[日用说明](<daily_keymouse.md>)，未填前不把旧UF2改名当本版。

完整11ee89e是本轮保留功能的源码基线，不等于“已去手柄”的旧二进制。历史 `79b7b7c` 曾获键鼠正面反馈，但仅含v2.2.1旧功能，回退会失去后续已认可玩法；其历史SHA为 `cb89bd9060347df06c5c66f7010afcb821513309ed14312c5e37a12ee3fd30b1`，不是本版哈希。其他旧件见[历史交付记录](<../firmware-delivery/XBOX_CURRENT.md>)；旧GBA、Xbox与安卓最后候选仅保留历史，不要求再刷、不继续手柄测试。

回退由用户决定；旧验收不外推本轮。普通UF2不等于settings_reset，也不保证覆盖Studio已保存键图。不得擅自刷写、清配对、擦设置或改主机。移除手柄服务会改变服务布局/GATT hash，保留身份和配对不等于保证所有旧主机缓存零影响。

## 21 排错：轻拍、滚轮、灯和连接

| --- | --- |
| 重启后轻拍失效 | 默认 OFF；普通层对当前左键角色肩键重新快速三击（翻转模式下为右肩），松手后等约 1 秒 |
| 小位移抖动 / 速度不匀 | 已刷v2.3.2仅有限改善；现可UPPER Z选低档，系统加速仍影响，不清配对 |
| Z不记忆/不连跳 | 仅UPPER；松开再按；末次等≥1秒保存，见16章 |
| 刚机械点击完轻拍没反应 | 持有和释放后的约 600ms 原生保护正常；先分开操作 |
| 连续轻拍只出一次 | 过快可能未达 300ms 间隔或静止重武装；主机双击也有自身条件 |
| 小范围搓动仍单击 | 短促微动仍可能符合轻拍；新迟滞只对已进入超限滑动路径有效 |
| 滑动后立刻轻拍不认 | 连续静止满 300ms 才重武装；中间移动会重新计时 |
| 松右 aA 仍滚动 | 检查滚轮是否已锁定；重入aA层再快双击右aA解锁，SYM退层不解锁 |
| MEDIA按键无字、机械点击无左键 | 原默认为39个显式None，不透明回落；用$/SYM/右aA回普通层。None不等于停掉触板传感器 |
| 左键肩键稍有延迟 | 等三击识别；翻转模式下左键角色在物理右肩 |
| 触板灯亮但键盘灯不亮 | 两套亮度和空闲门控不同；查V开关、亮度0，并按普通物理键 |
| 调暗后一断电没保持 | 两盏分别调一次，等约 1 秒再关；核对固件版本，别拿动画低点当设定丢失 |
| 插线仍向蓝牙输出 | 查当前槽、连接就绪和输出偏好，选槽与选传输不同 |
| 蓝牙无字 / 无指针 | 选对已连接槽；aA+Q 只选 BLE 偏好，不会凭空建立连接 |

## 22 Studio 改键与固件默认的区别

**本固件启用 ZMK Studio，且关闭了 Studio 锁定。** 没有额外配置“解锁组合键”，不要去试重启或清配对来解锁。可从 [ZMK Studio](<https://zmk.studio/>)的受支持连接入口连接；具体浏览器 / 客户端和串口权限以当前主机支持为准。

优先用 USB 数据线，在工具里选择 Studio 的 RPC 接口；固件还存在单独的 debug 日志 CDC，**日志口不是 Studio RPC 口**。看不到兼容设备时先排查数据线、枚举、接口和已有占用，不为此自动清设置、重刷或改系统权限。

### 只想看键位，和真正改键，分开做

- 查看默认键图以本书和源码为准；查看已保存自定义要读取当前设备的 Studio 状态。
- 真要修改前，保留原布局 / 导出记录，核对层号和物理位置，只改明确需要的位置。
- 保存到设备的改键可能覆盖编译默认值；**普通应用 UF2 重刷不等于清除 Studio 设置**。
- 改动后逐层验证关键键、返回出口、鼠标与维护键，再更新说明书。

### 这些附加行为不只存在于键图

P37减速、P41滚动/锁轮、P40+P41组合Ctrl仍有物理监听；UPPER由aA行为仲裁持有。仅改键图不会删除监听。**Z调速是正常可重映射behavior，不是隐藏物理监听**；已保存Studio布局可能覆盖新默认Z，先查布局，不清设置。

MEDIA 的 None 不删除监听，也不是传感器关闭指令；本版已经移除手柄独占 / 晚发送门，保留原键鼠路径、P37减速与P41滚轮等物理监听。P35($)、P40(SYM)、P41(右aA)三个出口回DEFAULT。重排键位仍须同时审查驱动。

**MEDIA看起来“留空”或设备仍显示旧自定义？** 编译原默认为39None＋3出口，不是42键全空。先核对实际固件和第17章；确曾保存Studio改键才另查保存布局，新默认不保证覆盖旧自定义。历史失败不能在无证据时归因Studio；不要清设置、刷settings_reset或清配对。

本书按章定位；PDF / Word 实际分页与键图仍须导出 QA。
