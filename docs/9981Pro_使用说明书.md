# 9981 Pro 使用说明书

手册 v2.2.1.6 · 2026-10-25 · 适用 9981 Pro / P9981，板型 bbp9981，非 Air。

## 01 先记住这八件事

**本轮只接回手柄运行时和工作线程。** 底座为用户确认正常的USB枚举版；原键图、触板和轻拍代码不改，无手柄输入绑定。BLE仍为原196B键鼠Map，手柄BLE出口返回不支持；USB允许原运行时发初始中立报告。请只测普通层，先不进入MEDIA；不是可玩手柄版。

| 你要做什么 | 最短操作 |
| --- | --- |
| Mac / iPad 的 Cmd | 普通层按触板左边的黑莓键 |
| 临时滚动 | 按住**右下 aA**，再滑触控板 |
| 锁定 / 取消滚轮 | 独立快双击右下 aA |
| Ctrl + 方向键 / 滚轮 | 同时按住右 aA 和 SYM，先后顺序都可以 |
| 数字和符号 | 点 SYM 用一次；按住 SYM 连续用 |
| 启用 / 关闭轻拍点击 | 普通层快速三击左肩；**重启后默认关闭** |
| 键盘背光调暗 / 调亮 | 右 aA + C / M |
| 触控板灯调暗 / 调亮 | 右 aA + V / N |

**三个“双击”不是一回事：** 左肩双击是鼠标操作；右 aA 双击是滚轮锁定；触控板连续轻拍是算法产生的鼠标单击，主机再判断双击。不要互相套用时间阈值。

**危险键先看第 18 页。** aA 层的 R 会重启；触板机械双击清当前蓝牙槽；$ 单击进刷机引导。它们并没有统一的“长按才生效”保险。

## 04 四层与短按、按住

| 层 | 怎么进入 | 怎么退出 / 何时结束 |
| --- | --- | --- |
| 0 普通层 | 开机默认、层返回操作 | 日常字母与鼠标 |
| 1 SYM | 点一下 SYM；或按住；普通层双击 $ 可固定进入 | 一次性用下一次键码或约 3 秒超时；固定层按 SYM 回普通 |
| 2 aA / UPPER | 点一下右 aA；或按住右 aA | 一次性用一次或约 3 秒超时；按住则松开结束，原有固定层另算 |
| 3 MEDIA | SYM 层快双击 $ | 按 $、SYM 或右 aA 回普通层 |

**一次性层：** 点一下、松开层键，再按目标键；适合单个数字、符号、方向。新按下的修饰键也可能消耗一次性层，因此组合操作先按修饰键，再进层。

**临时层：** 按住层键再操作，适合连续输入；层键是 hold-preferred，期间按其他键可提前确认为按住，不必故意等满 450ms。

| 行为 | 当前时间参数 |
| --- | --- |
| SYM、右 aA、普通层左 Ctrl 的短按 / 按住 | 450ms |
| 返回 / 结束通话、SYM 的 T / Y 长短按 | 默认 mod-tap 约 200ms；按键交叠也影响裁决 |
| 一次性层未用超时 | 3000ms |
| 左 Ctrl 一次性修饰未用超时 | SDK 默认约 1000ms |
| $ 的 tap-dance / aA 层触板 tap-dance | 400ms；不是轻拍点击间隔 |

滚轮锁定与当前层分别保存状态；锁住滚轮不会把键盘一直固定在 aA 层。

## 05 左肩、右肩与机械点击

**普通层：** 左肩和触板机械按压都是左键，右肩是右键。机械点击与轻拍算法互不等同；关闭轻拍后仍可正常用机械鼠标键。

| 左肩动作 | 结果 |
| --- | --- |
| 单击 | 普通左键单击；为等待可能的三击，可能稍后输出 |
| 双击 | 保留两次左键，双击效果由主机判断 |
| 按住并移动触板 | 左键拖动；移动时提交按下，不继续等三击 |
| 快速完整三击 | 切换轻拍 ON / OFF；这三下被开关消费，不额外发三次鼠标点击 |

**三击做法：** 回普通层，不滑触板、不夹其他键，左肩连续按下并松开三次。每拍按住不超过 180ms，两拍之间从上次松开到下次按下不超过 220ms。

**为什么左肩单击可能略慢？** 若没有继续点击，待第三拍识别窗口结束才回放单 / 双击；按住超过 180ms、出现移动或其他键可结束识别并交回普通鼠标操作。原始事件顺序保留，但不是“零延迟”。

切层、切主机、连接变化会取消不该跨上下文发送的待处理序列。不要在切槽或切层途中做三击。

三击开关仅绑定普通层左肩；SYM 的左肩是音量加，aA 的左肩是滚轮上，MEDIA 的肩键无输出。不要在这些层用三击尝试开关。

## 06 指针、拖动与滚轮

### 移动与精细定位

普通状态滑动触板移动指针。固件保留小数位移，不生成惯性；系统仍可对鼠标做自己的速度和加速度处理。

**按住物理左下 aA（实际 Ctrl）可减速。** 固件普通增益为 1.2，物理减速为 0.6；这里是传感器计数到 HID 相对位移，不是主机屏幕上的绝对速度保证。一次性 Ctrl、右 aA + SYM 生成的 Ctrl，不等同于按住这颗物理减速键。

### 临时滚动与锁定滚轮

| 目的 | 操作 |
| --- | --- |
| 临时滚动 | 按住右下 aA，滑触板；松开恢复此前滚轮状态 |
| 锁定 / 取消锁定 | 独立快双击右下 aA，第二拍松开时切换 |
| 用实体键滚动 | 在 aA 层按左肩 / 右肩，分别为滚轮上 / 下 |
| 方向键 | aA 层 W / A / S / D = ↑ / ← / ↓ / → |

右 aA 双击要求两拍各短于 450ms，第一拍松开到第二拍按下间隔不超过 350ms，中间不能夹其他键；长按、Ctrl 组合会打断这次锁定识别。**重启后滚轮锁定关闭。**

触板滚动包含纵向 Wheel 和横向 AC Pan；滚速有固件内的累积与速度曲线，不由灯光亮度控制。方向、横向支持、缩放等最终效果取决于系统设置、App 和焦点。

滚轮模式不同时识别轻拍点击。若松开右 aA 后仍在滚动，先检查是否已经锁定，不要靠清配对来解决。

## 07 轻拍：可选的运动启发式

**开机默认 OFF。** 在普通层快速三击左肩开 / 关；开关不持久保存，重启后要重新开启。没有专属 ON / OFF 灯态：不要把 USB 呼吸、滚轮呼吸当成轻拍开关指示。

建议先开启、松开所有键，等约 1 秒再试。做一次短促轻拍，然后自然停下；不要为“更容易触发”持续用力搓动。

| 当前资格条件 | 数值 / 含义 |
| --- | --- |
| 推算净指针位移 | 3–50px（含边界），经同一正常 / 减速增益计算 |
| 非零运动帧 | 1–8 帧；第九帧转为普通移动 |
| 首末运动跨度 | 不超过 120ms |
| 运动后静止确认 | 至少 120ms 的有效零运动轮询 |
| 自动点击最小间隔 | 至少 300ms；不是主机双击识别上限 |
| 原生机械活动保护 | 持有时阻止自动点击，释放 / 末次活动后再保护约 600ms |

**它不是可靠的触点 / 抬指识别。** 传感器运动满足短、位移合适、随后安静，算法就可能认为是一次点击。因此轻擦、小搓动、短促滑动也可能误点；完全没有运动量的轻触也可能不点。

候选命中时会消费那组运动；不合格时按原始帧回放为指针移动。因此开启后某些小移动可能先被短暂缓冲，不能称零延迟。

300ms 最小间隔允许部分自然双击节奏通过，但主机还要看自己的双击时间、位置等规则。过快两次轻拍可能只得到一次；也不提供双指右键、三指手势或可靠的轻拍拖拽。

## 08 轻拍时间与滑动后迟滞

**三个“等一下”分开理解，不能把数值简单相加。** 它们在不同状态生效，且多项时间并行计算。

| 时间 | 从哪里算 | 作用 |
| --- | --- | --- |
| 120ms 静止确认 | 候选的最后一帧运动 | 观察短促运动是否真的停下，不是无线发送后等待 |
| 200ms 普通重武装 | 普通候选 / 自动点击路径的末次运动 | 回弹期间不立刻生成新候选 |
| 300ms 滑动重武装 | 明确超限滑动路径的最后一次运动 | 延长滑动后保持普通指针的时间 |
| 300ms 自动点击间隔 | 前一次自动点击判定 / 输出接受保护 | 太近的自动点击丢弃，不排队补发 |
| 约 600ms 原生保护 | 原生机械 / 左肩活动与释放 | 避免紧跟机械点击再自动补一次 |

### 这版新增迟滞，能挡什么

运动超过 50px 屏幕推算范围、跨度超过 120ms、超过帧数等上限后，进入较长的滑动通道。此后要**连续静止满 300ms**才重新识别轻拍；期间哪怕只轻轻挪一下，也按普通移动输出并重新计时。

### 它不能挡什么

刚开始的小搓动若始终落在 3–50px、1–8 帧、120ms 内，又静止 120ms，仍可能直接满足轻拍条件，根本没进入“明确滑动”通道。**延长滑后迟滞不是消除所有小范围误点的保证。**

静止必须来自有效传感器轮询；断流、读错、无数据不能假装抬指。太旧候选、时钟异常或上下文变化会取消，不会补发迟到点击。已经发出的自动点击也不能被未来的机械点击撤回。

## 09 Cmd、Ctrl、Shift 与多选

### 普通快捷键

普通层先按住黑莓键，再按 C / V / X / Z / A 等，发 Cmd（左 GUI）组合；在 Windows 常对应 Win，安卓及各 App 的行为以主机为准。键盘不会自动把 Cmd 换成 Ctrl。

左下 aA 是 Ctrl：按住可连续组合；点一下松开则是一次性 Ctrl，随后一颗非修饰键使用它，未用约 1 秒超时。Z 左边的 alt 键帽实际是 Shift。

### 右 aA + SYM：双顺序都能 Ctrl

从普通层开始，同时实际按住右 aA 与 SYM，**先 aA 后 SYM、先 SYM 后 aA 都支持**。此时输出左 Ctrl；任意一颗松开就释放这份 Ctrl，保留另一颗再重按也能重新组成。

仅处于一次性 aA 层、或只锁定滚轮，但右 aA 已松手，不满足双键 Ctrl。在一次性 aA 层按 SYM 会回普通层。MEDIA 不新增这组 Ctrl 组合。

**不要拿它直接做 Ctrl+C / V：** aA 层 C / V 是灯光调节，不是字母；日常字母快捷键用普通层左下 Ctrl。

### Cmd + 鼠标多选 / 拖动

先在普通层按住黑莓 Cmd，再用触板机械左键或左肩；需要范围选择时可先按住 Shift 再点击。主机软件必须支持相应选择方式。

同源菜单 + 点击已有用户正面反馈，但这不等于验证了任意多键无冲突。遇到串键、粘键先松开；不要为证明全键无冲突盲试多颗维护键。

## 12 Shift 扩展与组合输入示例

### 输入 % 或美元符号

1. 在普通层按住 Z 左侧的 alt 键帽（真实 Shift）。
2. 短点 SYM 并松开，Shift 一直保持。
3. 按 D 得 %，按 S 得 $，最后松开 Shift。

也可一直按住 SYM 与 Shift 连续输入。**先点 SYM 再补按 Shift**可能把一次性层消耗掉，最后按 D 就不是数字 5。

| SYM 数字 | 加 Shift 后 | 已有直接绑定 |
| --- | --- | --- |
| 1 / 2 / 3 | ! / @ / # | SYM + B / P / Q |
| 4 / 5 / 6 | $ / % / ^ | 前两项用 Shift；^ 可右 aA + L |
| 7 / 8 | & / * | 右 aA + H；SYM + A |
| 9 / 0 | ( / ) | SYM + 短按 T / Y |

### 组合顺序：先修饰键，再进层

| 例子 | 操作顺序 |
| --- | --- |
| Cmd + 1 | 普通层保持黑莓 → 点 SYM 松开 → W |
| Cmd + Shift + 3 | 保持黑莓与 Shift → 点 SYM 松开 → R |
| Shift + 方向选择 | 保持 Shift → 点右 aA 松开 → W / A / S / D |
| 连续 Ctrl + 方向 | 实际保持右 aA 与 SYM → W / A / S / D |

**Cmd 要先从普通层按下。** 已进 SYM 再按黑莓是搜索，已进 aA 再按黑莓是选择蓝牙槽 1。按下时所属层决定它这次的绑定。

## 13 aA 层：导航、设备与维护

![aA层完整键位图](<说明书图示/03_aA层.svg>)

| 实体位置 | aA 层功能 |
| --- | --- |
| 左肩 / 右肩 | 滚轮上 / 下 |
| 通话 / 黑莓 / 返回 / 结束 | 蓝牙槽 0 / 1 / 2 / 3 |
| Q / W / E / R / T | 选 BLE 输出偏好 / ↑ / Eject / 重启 / 外设供电切换 |
| A / S / D；U / I / O / P | ← / ↓ / →；< / > / 竖线 / 小键盘等号 |
| G / H / J / K / L | 反斜杠 / & / { / } / ^ |
| C / B / M | 键盘灯亮度减 / 开关 / 加（RGB 状态） |
| V / N | 触板灯亮度减 / 加（BL 状态） |
| 触板机械按压 / $ | 单击左键、双击清当前槽 / 单击刷机、双击切输出 |
| F / Y / Z / X | 无输出；不是透明回普通层 |
| ← / alt键帽 / 左下aA / 底行0 | 退格 / Shift / Ctrl / Alt |
| 空格 / Enter / SYM / 右aA | 空格 / 回车 / 条件 Ctrl 或退出 / 回普通层 |

红色功能必须先读第 18 页。Q 是后来新增的安全 BLE 偏好入口；**不要为切 BLE 去冒险双击 aA 层的 $。**

## 14 蓝牙槽与 USB / BLE 输出

### 选择四个蓝牙槽

从普通层按住右 aA，再按通话 / 黑莓 / 返回 / 结束，分别选槽 0 / 1 / 2 / 3。空槽可在主机蓝牙设置配对，已配对槽用于切回对应设备；具体广告和重连受主机与槽状态影响。

默认键图提供这**四个独立槽位的直达键**，不固定对应 Mac、安卓、iPad；这不等于蓝牙总容量只有四槽。正常切换设备只选槽，不要清槽，也不要清全部设置。

### 插线不等于一定向 USB 输出

输出选择由 USB 就绪、当前蓝牙槽连接状态、保存的输出偏好共同决定。选蓝牙槽不等于选 BLE 传输；USB 仍可能是当前输出。

| 要做什么 | 当前入口与注意事项 |
| --- | --- |
| 优先 BLE | 右 aA + Q；这是 OUT_BLE 偏好，不强迫未连上的蓝牙立刻工作 |
| 在 USB / BLE 偏好间切换 | aA 层 $ 快双击；单击项是刷机，谨慎，见第 18 页 |
| USB 键盘 / 鼠标 | 用 USB 数据线连接能枚举 HID 的主机，并确认实际输出端点 |
| 给电脑 USB 充电但用蓝牙 | 是否可行取决于当前就绪和输出偏好，不以“插着线”判断 |

选 BLE 后若活动槽尚未连接，不要误认为按键损坏；先核对槽和主机连接。不要靠清配对来反复试选路。日志串口、充电、USB HID 就绪、BLE 连通是不同状态。

## 15 灯光：两套亮度，分开调

| 想调哪盏 | 调暗 / 调亮 | 开关 |
| --- | --- | --- |
| 键盘背光 | 右 aA + C / M，读取 RGB 用户亮度 | 右 aA + B，RGB 开关 |
| 触控板指示灯 | 右 aA + V / N，读取 BL 用户亮度 | 默认未给 BL 单独开关键；可调到 0 |

本版两套控制分别接入实体键盘灯和触板灯，不能再沿用旧说明书“V/N 不一定影响触板”的说法。它们也**不会改变指针或滚轮速度**。

### 键盘灯表示当前层

| 最高活动层 | 活跃时效果 |
| --- | --- |
| 普通层 0 | 按键授权后常亮；刚启动或空闲恢复不一定立刻亮 |
| SYM 层 1 | 高低亮交替，稳态每约 500ms 换一次 |
| aA 层 2 | 20ms 一步的呼吸变化 |
| MEDIA 层 3 | 更快高低亮交替，稳态每约 250ms 换一次 |

### 触板灯表示当前所选输出与活动

**USB 输出：** 约 1 秒一周期的平滑呼吸，覆盖滚轮动画；不是旧版每秒短闪，也不是电池已充满或轻拍已开启的证明。

**BLE 输出：** 滚轮模式呼吸；普通运动活动时点亮，末次活动后约 5 秒熄灭。此处“活动”来自运动读取，不是可信的手指接触检测。

## 16 亮度记忆、空闲与恢复

### 亮度会记住什么

键盘和触板各自保存**用户原始亮度设定**，不是保存当前动画那一瞬间的亮度。动画到暗处、空闲熄灯，不会因此把用户亮度写成 0；用户真调到 0 则可以保存。

调好后等约 1 秒再关机 / 断电，给合并保存工作留时间。已丢失的旧设定不会自动找回，第一次需要重新调一次。记忆实现存在，不等于本书新增做过设备断电验收。

键盘 B 开关仍遵循 RGB 原生状态；触板没有同样的默认 B 开关。**关键盘灯不等于关触板灯。**

### 最低亮度和动画

两路键盘 PWM 与触板 PWM 使用低亮度细分路径，保留小数占空比，载波约 2kHz；USB 触板呼吸以约 20ms 更新。低亮度不是靠软件低频开关灯模拟。

触板末端输出另外压到原比例约 1/3，以降低过亮；这不是测光结果，也不保证与键盘视觉亮度恰好一致。

### 空闲并不等于关机

配置的空闲时间约 30 秒，且本版**系统深睡配置关闭（SLEEP=n）**，不是 30 秒自动关机。键盘四层动画在 idle 都会停止，回普通层通常需一次物理按键重新允许点亮；只滑触板不能保证点亮键盘背光。

触板 USB 呼吸不使用相同的键盘 idle 门控，BLE 普通活动另有约 5 秒熄灯逻辑。不要用某一盏灯判断整机已休眠、主机断开或电池电量；本说明书不承诺未核验的续航、深睡时间或电量百分比。

## 17 MEDIA 层与“按了没反应”

![MEDIA层完整键位图](<说明书图示/04_MEDIA层.svg>)

**这是一个基本留空的第 3 层，不是完整媒体控制面板。** 从 SYM 层快双击 $ 进入；大多数位置显式绑定为无输出。

| 本层位置 | 当前功能 |
| --- | --- |
| $ | 回普通层 |
| SYM | 回普通层 |
| 右下 aA | 回普通层 |
| 其他所有位置，包括肩键、字母、空格、Enter | 无输出；不会自动回落到普通层 |

本项目四层均完整写出绑定，没有用透明键自动透传普通层。aA 层 F / Y / Z / X、MEDIA 留空键不输入字母是设计状态，不是卡键。

如果不知道自己在哪层：先松开所有键；一次性层未用约 3 秒会结束，但固定层不会因此自动退出。按当前层的明确出口回普通层；**不要乱试 aA 的 R、T、$ 或触板双击。**

灯光可辅助看层：SYM 慢闪、aA 呼吸、MEDIA 快闪；但灯被关掉、调到 0 或进入 idle 时不能仅靠灯判断。

## 18 维护键：确认后再按

以下都指 **aA / UPPER 层**，不是普通字母键。日常打字不需要这些操作。

| 操作 | 实际结果与风险 |
| --- | --- |
| R 按一次 | 重启键盘本体，不是重启电脑 |
| 触板机械单击 | tap-dance 的单击项是鼠标左键 |
| 触板机械快双击 | 清当前选中蓝牙槽配对，不是清所有槽 |
| $ 单击 | 进入 bootloader 刷机引导，正常使用会中断 |
| $ 快双击 | 切 USB / BLE 输出偏好；不够快可能先触发刷机 |
| T 按一次 | 切外设电源，不是主电源，也不是安全的“关灯键” |
| E | 发送 Eject；主机是否处理由系统决定 |

**这里的触板按键是机械按压，不是轻拍算法。** 滚轮模式下轻拍不会替你执行上述 tap-dance；不要把普通层轻拍双击和清配对操作混为一谈。

$、触板 tap-dance 的窗口是 **400ms，从首击按下起算，不是从松开起算**；第二次按下即选择双击项。已超时或被其他键打断时，单击项可能已经执行。按住 $ 到超时也可能进 bootloader，**没有额外长按安全锁**。

切 BLE 优先用 aA + Q。清当前槽仅在确实要重新配对时使用，并准备在主机端处理旧配对记录；不把清配对、settings_reset 或擦整片闪存当成常规排错步骤。

## 19 更新固件与安全回退

### 手动刷写

1. 核对硬件为 **9981 Pro / bbp9981**，固件不能与 Air 或其他型号混用。
2. 保留当前可回退的 UF2 和 SHA-256。先确认有可靠的引导 / 回退路径；本书不猜实体复位键位置，也不要求拆机。
3. 用 USB **数据线**连接能挂载 UF2 磁盘的电脑，再通过已确认的引导入口进入 bootloader。
4. 将核对好的 UF2 复制到出现的刷机磁盘。无需改名，识别依据是内部格式与目标信息。
5. 等复制完成和设备自动重启；磁盘消失常属正常。不要复制中断电或拔线。

蓝牙不会提供 UF2 磁盘。进入 bootloader 不等于已经写入固件；下载完成、构建成功、刷入、实机确认是四个阶段。更新后逐项检查普通键、机械点击、组合键、两套灯，再按需三击开启轻拍。

### 版本与回退

用户已重新确认正常的原v2.0回退 UF2 SHA-256 为 `e0c20d4dc2d35d5fe6395e4574ad7bb4272d92d3269b6452af95e2d87dcbb94d`。

保留的 ab18d4 精确回退 SHA-256 为 `ab18d4b5c651a6c97d74cc99ef44a24e296810dc1826cce7e29560d83e5a3606`。它保留当时其他功能，但轻拍是另一套判据；不是本版参数的同名备份。

本轮已授权构建运行时单变量候选；**不自动刷写、清配对或修改主机设置**。本轮来源见第23章，上方摘要是正常原版回退而非新候选。

## 20 排错：键位与组合键

| 现象 | 优先检查 |
| --- | --- |
| 黑莓键不发 Cmd | 是否普通层？SYM 是搜索，aA 是蓝牙槽 1，MEDIA 无输出 |
| 底行 0 变 Alt | 普通层本来就是 Alt；数字 0 要进入 SYM |
| alt 键帽变大写 | 它实际是 Shift，左下 aA 才是 Ctrl |
| $ 不是美元 | 普通层是分号 / 双击 SYM；美元用 Shift + SYM 的 S |
| 想输 % 却出了 D | 先保持 Shift 再点 SYM，避免修饰键消耗一次性层 |
| 大括号变方括号 | SYM 长按 T/Y 是 [ ]；aA 的 J/K 直接是 { } |
| 进入层后字母没反应 | aA 的 F/Y/Z/X 与 MEDIA 大部分键是显式无输出 |
| aA + SYM 没有 Ctrl | 两颗是否实际按住？仅一次性层或锁轮不算；MEDIA 不新增组合 |
| Ctrl+C 变调灯 | 右 aA + SYM 会留在导航功能层；普通字母快捷键用左下 Ctrl |
| 多选不按预期 | Cmd / Shift 要先从普通层保持；核对 App 是否支持；不要断言所有多键都无冲突 |
| 说明书与实体不一致 | 核对实际固件和 Studio 改键；再查系统布局、输入法和焦点 |

先松开所有键、回普通层再重试。固定 SYM 用 SYM 退出，MEDIA 用 $ / SYM / 右 aA 退出。不要通过维护键“碰运气恢复”。

## 21 排错：轻拍、滚轮、灯和连接

| 现象 | 优先检查 |
| --- | --- |
| 重启后轻拍失效 | 默认 OFF；普通层重新快速三击左肩，松手后等约 1 秒 |
| 三击后不确定开没开 | 没有专属状态灯；三击可能受按住太久、间隔、移动或切层打断 |
| 刚机械点击完轻拍没反应 | 持有和释放后的约 600ms 原生保护正常；先分开操作 |
| 连续轻拍只出一次 | 过快可能未达 300ms 间隔或静止重武装；主机双击也有自身条件 |
| 小范围搓动仍单击 | 短促微动仍可能符合轻拍；新迟滞只对已进入超限滑动路径有效 |
| 滑动后立刻轻拍不认 | 连续静止满 300ms 才重武装；中间移动会重新计时 |
| 松右 aA 仍滚动 | 检查滚轮已锁定；独立双击右 aA 取消 |
| 左肩点击稍有等待 | 三击识别窗口会暂存单 / 双击，属于当前设计 |
| 触板灯亮但键盘灯不亮 | 两套亮度和空闲门控不同；检查 B 开关、亮度 0，并按普通物理键 |
| 调暗后一断电没保持 | 两盏分别调一次，等约 1 秒再关；核对固件版本，别拿动画低点当设定丢失 |
| 插线仍向蓝牙输出 | 查当前槽、连接就绪和输出偏好，选槽与选传输不同 |
| 蓝牙无字 / 无指针 | 选对已连接槽；aA+Q 只选 BLE 偏好，不会凭空建立连接 |

误点影响操作时先三击关闭轻拍，使用机械点击；需要回退由用户自行决定，不因排错自动清设置或重刷。

## 22 Studio 改键与固件默认的区别

**本固件启用 ZMK Studio，且关闭了 Studio 锁定。** 没有额外配置“解锁组合键”，不要去试重启或清配对来解锁。可从 [ZMK Studio](<https://zmk.studio/>)的受支持连接入口连接；具体浏览器 / 客户端和串口权限以当前主机支持为准。

优先用 USB 数据线，在工具里选择 Studio 的 RPC 接口；固件还存在单独的 debug 日志 CDC，**日志口不是 Studio RPC 口**。看不到兼容设备时先排查数据线、枚举、接口和已有占用，不为此自动清设置、重刷或改系统权限。

### 只想看键位，和真正改键，分开做

- 查看默认键图以本书和源码为准；查看已保存自定义要读取当前设备的 Studio 状态。
- 真要修改前，保留原布局 / 导出记录，核对层号和物理位置，只改明确需要的位置。
- 保存到设备的改键可能覆盖编译默认值；**普通应用 UF2 重刷不等于清除 Studio 设置**。
- 改动后逐层验证关键键、返回出口、鼠标与维护键，再更新说明书。

### 这些附加行为不只存在于键图

物理位置 P37 的减速、P41 的按住滚动 / 双击锁轮、P40+P41 的双顺序 Ctrl，都由驱动监听位置实现。仅把键帽对应绑定改成另一功能，**不会自动删除这些监听行为**；层键本身的原操作也不会被组合 Ctrl 全部吞掉。

当前 MEDIA 的“无输出”指键码绑定，不保证把指针驱动的所有物理监听关闭。准备大幅换层键或重排布局时，要同时审查驱动，不能只改表格。
