# 9981 Pro 使用说明书

手册 v2.2.5 · 2026-10-20 · 适用 9981 Pro / P9981，板型 bbp9981，非 Air。

## 01 先记住这九件事

**键帽用于定位，实际输出以当前层为准。** 本书保留键鼠基线说明；Xbox 为 **标准 HID**（非原生 XInput），GBA 候选已撤回。v2.2.5 本地候选：aA 双击锁轮并固定 UPPER，默认不旋转；右肩三击左→上，左肩三击右→上，每次转90°，解锁 / 重锁回正。锁定肩键半速并屏蔽自身滚轮；按住 aA 临时恢复原方向与原生肩键滚轮。**未推送、未 ARM 构建；已发布 v2.2.4 UF2 是旧方向。** 状态见第 23–25 章，虚拟摇杆见第 26 章。

| 你要做什么 | 最短操作 |
| --- | --- |
| Mac / iPad 的 Cmd | 普通层按触板左边的黑莓键 |
| 临时滚动 | 按住**右下 aA**并滑触控板；松开结束临时滚动 |
| 锁定 / 取消滚轮 | 在 aA 层快双击右下 aA；切换锁轮并固定 UPPER，SYM 回普通层 |
| Ctrl + 方向键 / 滚轮 | 同时按住右 aA 和 SYM，先后顺序都可以 |
| 数字和符号 | 点 SYM 用一次；按住 SYM 连续用 |
| 启用 / 关闭轻拍点击 | 普通层快速三击左肩；**重启后默认关闭** |
| 键盘背光调暗 / 调亮 | 右 aA + C / M |
| 触控板灯调暗 / 调亮 | 右 aA + V / N |
| Xbox 布局手柄层 | 按住 SYM，快双击 $，再松开 SYM；键位见第 17 章，虚拟摇杆见第 26 章 |

前八项是普通键鼠操作；**MEDIA 游戏层触板不同时发鼠标 / 滚轮 / 轻拍**。默认滑动左杆，按住黑莓临时换右杆；E/X/S/F 为方向键，D/K 为 L3/R3，触板机械点击与空格都发 Guide/Xbox。

**三个“双击”不是一回事：** 左肩双击是鼠标操作；右 aA 双击是滚轮锁定/解锁，锁定时固定在 aA 层；触控板连续轻拍是算法产生的鼠标单击，主机再判断双击。不要互相套用时间阈值。

**危险键先看第 18 章。** aA 层的 R 会重启；触板机械双击清当前蓝牙槽；$ 单击进刷机引导。它们并没有统一的“长按才生效”保险。

## 04 四层与短按、按住

| 层 | 怎么进入 | 怎么退出 / 何时结束 |
| --- | --- | --- |
| 0 普通层 | 开机默认、层返回操作 | 日常字母与鼠标 |
| 1 SYM | 点一下 SYM；或按住；普通层双击 $ 可固定进入 | 一次性用下一次键码或约 3 秒超时；固定层按 SYM 回普通 |
| 2 aA / UPPER | 普通层短点右 aA 进入一次性；快双击锁轮；按住临时滚动 | 一次性到下一键/约 3 秒；按住则松开结束；双击固定 UPPER，SYM 退层；解锁仍留 UPPER |
| 3 MEDIA / Xbox 布局 | 按住 SYM 后快双击 $，再松开 SYM | 按 $、SYM 或右 aA 回普通层；取消旧队列，尝试发送 neutral |

**一次性层：** 点一下、松开层键，再按目标键；适合单个数字、符号、方向。新按下的修饰键也可能消耗一次性层，因此组合操作先按修饰键，再进层。

**临时层：** 按住层键再操作，适合连续输入；层键是 hold-preferred，期间按其他键可提前确认为按住，不必故意等满 450ms。

| 行为 | 当前时间参数 |
| --- | --- |
| SYM、右 aA、普通层左 Ctrl 的短按 / 按住 | 450ms |
| 返回 / 结束通话、SYM 的 T / Y 长短按 | 默认 mod-tap 约 200ms；按键交叠也影响裁决 |
| 一次性层未用超时 | 3000ms |
| 左 Ctrl 一次性修饰未用超时 | SDK 默认约 1000ms |
| $ 的 tap-dance / aA 层触板 tap-dance | 400ms；不是轻拍点击间隔 |

aA 双击第二拍把 UPPER 固定，避免一次性层超时/键码 quick-release 令肩键 modifier 失效；按 SYM 退层。层与滚轮锁定独立：退层不解锁；需重入 aA 层再双击解锁。

## 05 左肩、右肩与机械点击

**普通层：** 左肩和触板机械按压都是左键，右肩是右键。机械点击与轻拍算法互不等同；关闭轻拍后仍可正常用机械鼠标键。

| 左肩动作 | 结果 |
| --- | --- |
| 单击 | 普通左键单击；为等待可能的三击，可能稍后输出 |
| 双击 | 保留两次左键，双击效果由主机判断 |
| 按住并移动触板 | 左键拖动；移动时提交按下，不继续等三击 |
| 快速完整三击 | 切换轻拍 ON / OFF；这三下被开关消费，不额外发三次鼠标点击 |

**三击做法：** 回普通层，不滑触板、不夹其他键，左肩连续按下并松开三次。每拍按住不超过 180ms，两拍之间从上次松开到下次按下不超过 220ms。

**为什么左肩单击可能略慢？** 若没有继续点击，待第三拍识别窗口结束才回放单 / 双击；按住超过 180ms、出现移动或其他键可结束识别并交回普通鼠标操作。原始事件顺序保留，但不是“零延迟”。

切层、切主机、连接变化会取消不该跨上下文发送的待处理序列。不要在切槽或切层途中做三击。

三击开关仅绑定普通层左肩；SYM 的左肩是音量加，aA 的左肩是滚轮上，**MEDIA 的左右肩是数字 LT / RT**，通话 / 结束才是 LB / RB。不要在这些层用三击尝试开关。

MEDIA 的触板机械按压不是鼠标左键：DOWN 固定输出 Guide/Xbox，UP 释放；不按黑莓模式改成 L3/R3。L3/R3 分别由 D/K 输出。虚拟杆模式见第 26 章。

## 06 指针、拖动与滚轮

### 移动与精细定位

以下为非 MEDIA 游戏层的原鼠标路径：普通状态滑动触板移动指针。固件保留小数位移，不生成惯性；系统仍可对鼠标做自己的速度和加速度处理。MEDIA 层触板改作虚拟杆，不同时移动鼠标 / 滚轮；P37 的物理减速监听不是摇杆加速，详见第 26–27 章。

**按住物理左下 aA（实际 Ctrl）可减速。** 固件普通增益为 1.2，物理减速为 0.6；这里是传感器计数到 HID 相对位移，不是主机屏幕上的绝对速度保证。一次性 Ctrl、右 aA + SYM 生成的 Ctrl，不等同于按住这颗物理减速键。

### 临时滚动与锁定滚轮

| 目的 | 操作 |
| --- | --- |
| 锁轮 / 回正 | 右下 aA 快双击锁轮并固定 UPPER，默认不旋转；双击退出再重锁回正 |
| 右肩三击 | 锁定时每组三击转90°：左→上、上→右；完整向量同步递转，后续三击继续累积 |
| 左肩三击 | 锁定时反向转90°：右→上、上→左；与右肩步进相反 |
| 肩键 / 临时恢复 | 锁定时按住肩键半速并屏蔽自身 Wheel；未锁定时肩键原生滚动。持锁按住 aA 临时绕过旋转、恢复原生肩轮；松开回原角度 |

锁轮双击时序不变：两拍各短于 450ms，释放至下一按下 ≤350ms，不能夹其他键；SYM 退层，重启后锁轮关闭。

肩键三击仅锁定时识别：每拍按住 ≤180ms，松开至下一按下 ≤220ms；第三次松开只步进一次。后续完整三击累积；异侧肩键或其他键按下会取消未完成序列，三击不发肩键原生 Wheel。

原 Wheel / AC Pan 曲线、半速余量与 P37 物理 Ctrl 减速不变。要回正只需双击解锁再重锁，不必清配对或改主机设置。

## 07 轻拍：可选的运动启发式

**开机默认 OFF。** 在普通层快速三击左肩开 / 关；开关不持久保存，重启后要重新开启。没有专属 ON / OFF 灯态：不要把 USB 呼吸、滚轮呼吸当成轻拍开关指示。

MEDIA 游戏层临时阻断轻拍并取消此前候选，不自动改轻拍开关值；退出后回原鼠标路径。以下资格、时序与普通层三击开关均保留，未因本轮虚拟杆而调优；虚拟杆的 120ms 本地归零与轻拍的 120ms 静止确认是两件事。

建议先开启、松开所有键，等约 1 秒再试。做一次短促轻拍，然后自然停下；不要为“更容易触发”持续用力搓动。

| 当前资格条件 | 数值 / 含义 |
| --- | --- |
| 推算净指针位移 | 3–50px（含边界），经同一正常 / 减速增益计算 |
| 非零运动帧 | 1–8 帧；第九帧转为普通移动 |
| 首末运动跨度 | 不超过 120ms |
| 运动后静止确认 | 至少 120ms 的有效零运动轮询 |
| 自动点击最小间隔 | 至少 300ms；不是主机双击识别上限 |
| 原生机械活动保护 | 持有时阻止自动点击，释放 / 末次活动后再保护约 600ms |

**它不是可靠的触点 / 抬指识别。** 传感器运动满足短、位移合适、随后安静，算法就可能认为是一次点击。因此轻擦、小搓动、短促滑动也可能误点；完全没有运动量的轻触也可能不点。

候选命中时会消费那组运动；不合格时按原始帧回放为指针移动。因此开启后某些小移动可能先被短暂缓冲，不能称零延迟。

300ms 最小间隔允许部分自然双击节奏通过，但主机还要看自己的双击时间、位置等规则。过快两次轻拍可能只得到一次；也不提供双指右键、三指手势或可靠的轻拍拖拽。

## 08 轻拍时间与滑动后迟滞

**三个“等一下”分开理解，不能把数值简单相加。** 它们在不同状态生效，且多项时间并行计算。

| 时间 | 从哪里算 | 作用 |
| --- | --- | --- |
| 120ms 静止确认 | 候选的最后一帧运动 | 观察短促运动是否真的停下，不是无线发送后等待 |
| 200ms 普通重武装 | 普通候选 / 自动点击路径的末次运动 | 回弹期间不立刻生成新候选 |
| 300ms 滑动重武装 | 明确超限滑动路径的最后一次运动 | 延长滑动后保持普通指针的时间 |
| 300ms 自动点击间隔 | 前一次自动点击判定 / 输出接受保护 | 太近的自动点击丢弃，不排队补发 |
| 约 600ms 原生保护 | 原生机械 / 左肩活动与释放 | 避免紧跟机械点击再自动补一次 |

### 基线保留的滑动后迟滞，能挡什么

运动超过 50px 屏幕推算范围、跨度超过 120ms、超过帧数等上限后，进入较长的滑动通道。此后要**连续静止满 300ms**才重新识别轻拍；期间哪怕只轻轻挪一下，也按普通移动输出并重新计时。

### 它不能挡什么

刚开始的小搓动若始终落在 3–50px、1–8 帧、120ms 内，又静止 120ms，仍可能直接满足轻拍条件，根本没进入“明确滑动”通道。**延长滑后迟滞不是消除所有小范围误点的保证。**

静止必须来自有效传感器轮询；断流、读错、无数据不能假装抬指。太旧候选、时钟异常或上下文变化会取消，不会补发迟到点击。已经发出的自动点击也不能被未来的机械点击撤回。

## 09 Cmd、Ctrl、Shift 与多选

### 普通快捷键

普通层先按住黑莓键，再按 C / V / X / Z / A 等，发 Cmd（左 GUI）组合；在 Windows 常对应 Win，安卓及各 App 的行为以主机为准。键盘不会自动把 Cmd 换成 Ctrl。

左下 aA 是 Ctrl：按住可连续组合；点一下松开则是一次性 Ctrl，随后一颗非修饰键使用它，未用约 1 秒超时。Z 左边的 alt 键帽实际是 Shift。

### 右 aA + SYM：双顺序都能 Ctrl

从普通层开始，同时实际按住右 aA 与 SYM，**先 aA 后 SYM、先 SYM 后 aA 都支持**。此时输出左 Ctrl；任意一颗松开就释放这份 Ctrl，保留另一颗再重按也能重新组成。

仅处于一次性/固定 aA 层，或只锁定滚轮但右 aA 已松手，不满足双键 Ctrl；右 aA 已松手时按 SYM 回普通层。MEDIA 不新增这组 Ctrl 组合。

**不要拿它直接做 Ctrl+C / V：** aA 层 C / V 是灯光调节，不是字母；日常字母快捷键用普通层左下 Ctrl。

### Cmd + 鼠标多选 / 拖动

先在普通层按住黑莓 Cmd，再用触板机械左键或左肩；需要范围选择时可先按住 Shift 再点击。主机软件必须支持相应选择方式。

同源菜单 + 点击已有用户正面反馈，但这不等于验证了任意多键无冲突。遇到串键、粘键先松开；不要为证明全键无冲突盲试多颗维护键。

## 11 数字与全部符号速查

以下按美式英文布局说明；主机使用其他布局或中文输入法时，字形可能不同。“层键 + 位置”表示按住层键，再按目标实体键。

## 12 Shift 扩展与组合输入示例

### 输入 % 或美元符号

1. 在普通层按住 Z 左侧的 alt 键帽（真实 Shift）。
2. 短点 SYM 并松开，Shift 一直保持。
3. 按 D 得 %，按 S 得 $，最后松开 Shift。

也可一直按住 SYM 与 Shift 连续输入。**先点 SYM 再补按 Shift**可能把一次性层消耗掉，最后按 D 就不是数字 5。

| SYM 数字 | 加 Shift 后 | 已有直接绑定 |
| --- | --- | --- |
| 1 / 2 / 3 | ! / @ / # | SYM + B / P / Q |
| 4 / 5 / 6 | $ / % / ^ | 前两项用 Shift；^ 可右 aA + L |
| 7 / 8 | & / * | 右 aA + H；SYM + A |
| 9 / 0 | ( / ) | SYM + 短按 T / Y |

### 组合顺序：先修饰键，再进层

| 例子 | 操作顺序 |
| --- | --- |
| Cmd + 1 | 普通层保持黑莓 → 点 SYM 松开 → W |
| Cmd + Shift + 3 | 保持黑莓与 Shift → 点 SYM 松开 → R |
| Shift + 方向选择 | 保持 Shift → 点右 aA 松开 → W / A / S / D |
| 连续 Ctrl + 方向 | 实际保持右 aA 与 SYM → W / A / S / D |

**Cmd 要先从普通层按下。** 已进 SYM 再按黑莓是搜索，已进 aA 再按黑莓是选择蓝牙槽 1。按下时所属层决定它这次的绑定。

## 14 蓝牙槽与 USB / BLE 输出

### 选择四个蓝牙槽

从普通层按住右 aA，再按通话 / 黑莓 / 返回 / 结束，分别选槽 0 / 1 / 2 / 3。空槽可在主机蓝牙设置配对，已配对槽用于切回对应设备；具体广告和重连受主机与槽状态影响。

默认键图提供这**四个独立槽位的直达键**，不固定对应 Mac、安卓、iPad；这不等于蓝牙总容量只有四槽。正常切换设备只选槽，不要清槽，也不要清全部设置。

### 插线不等于一定向 USB 输出

输出选择由 USB 就绪、当前蓝牙槽连接状态、保存的输出偏好共同决定。选蓝牙槽不等于选 BLE 传输；USB 仍可能是当前输出。

| 要做什么 | 当前入口与注意事项 |
| --- | --- |
| 优先 BLE | 右 aA + Q；这是 OUT_BLE 偏好，不强迫未连上的蓝牙立刻工作 |
| 在 USB / BLE 偏好间切换 | aA 层 $ 快双击；单击项是刷机，谨慎，见第 18 章 |
| USB 键盘 / 鼠标 | 用 USB 数据线连接能枚举 HID 的主机，并确认实际输出端点 |
| 给电脑 USB 充电但用蓝牙 | 是否可行取决于当前就绪和输出偏好，不以“插着线”判断 |

选 BLE 后若活动槽尚未连接，不要误认为按键损坏；先核对槽和主机连接。不要靠清配对来反复试选路。日志串口、充电、USB HID 就绪、BLE 连通是不同状态。

## 15 灯光：两套亮度，分开调

| 想调哪盏 | 调暗 / 调亮 | 开关 |
| --- | --- | --- |
| 键盘背光 | 右 aA + C / M，读取 RGB 用户亮度 | 右 aA + B，RGB 开关 |
| 触控板指示灯 | 右 aA + V / N，读取 BL 用户亮度 | 默认未给 BL 单独开关键；可调到 0 |

### 键盘灯表示当前层

| 最高活动层 | 活跃时效果 |
| --- | --- |
| 普通层 0 | 按键授权后常亮；刚启动或空闲恢复不一定立刻亮 |
| SYM 层 1 | 高低亮交替，稳态每约 500ms 换一次 |
| aA 层 2 | 20ms 一步的呼吸变化 |
| MEDIA 层 3 | 更快高低亮交替，稳态每约 250ms 换一次 |

### 触板灯表示当前所选输出与活动

**USB 输出：** 约 1 秒一周期的平滑呼吸，覆盖滚轮动画；不是旧版每秒短闪，也不是电池已充满或轻拍已开启的证明。

**BLE 输出：** 滚轮模式呼吸；普通运动活动时点亮，末次活动后约 5 秒熄灭。此处“活动”来自运动读取，不是可信的手指接触检测。

## 16 亮度记忆、空闲与恢复

### 亮度会记住什么

键盘和触板各自保存**用户原始亮度设定**，不是保存当前动画那一瞬间的亮度。动画到暗处、空闲熄灯，不会因此把用户亮度写成 0；用户真调到 0 则可以保存。

调好后等约 1 秒再关机 / 断电，给合并保存工作留时间。已丢失的旧设定不会自动找回，第一次需要重新调一次。记忆实现存在，不等于本书新增做过设备断电验收。

键盘 B 开关仍遵循 RGB 原生状态；触板没有同样的默认 B 开关。**关键盘灯不等于关触板灯。**

### 最低亮度和动画

两路键盘 PWM 与触板 PWM 使用低亮度细分路径，保留小数占空比，载波约 2kHz；USB 触板呼吸以约 20ms 更新。低亮度不是靠软件低频开关灯模拟。

触板末端输出另外压到原比例约 1/3，以降低过亮；这不是测光结果，也不保证与键盘视觉亮度恰好一致。

### 空闲并不等于关机

配置的空闲时间约 30 秒，且本版**系统深睡配置关闭（SLEEP=n）**，不是 30 秒自动关机。键盘四层动画在 idle 都会停止，回普通层通常需一次物理按键重新允许点亮；只滑触板不能保证点亮键盘背光。

触板 USB 呼吸不使用相同的键盘 idle 门控，BLE 普通活动另有约 5 秒熄灯逻辑。不要用某一盏灯判断整机已休眠、主机断开或电池电量；本说明书不承诺未核验的续航、深睡时间或电量百分比。

## 18 维护键：确认后再按

以下都指 **aA / UPPER 层**，不是普通字母键。日常打字不需要这些操作。

| 操作 | 实际结果与风险 |
| --- | --- |
| R 按一次 | 重启键盘本体，不是重启电脑 |
| 触板机械单击 | tap-dance 的单击项是鼠标左键 |
| 触板机械快双击 | 清当前选中蓝牙槽配对，不是清所有槽 |
| $ 单击 | 进入 bootloader 刷机引导，正常使用会中断 |
| $ 快双击 | 切 USB / BLE 输出偏好；不够快可能先触发刷机 |
| T 按一次 | 切外设电源，不是主电源，也不是安全的“关灯键” |
| E | 发送 Eject；主机是否处理由系统决定 |

**这里的触板按键是机械按压，不是轻拍算法。** 滚轮模式下轻拍不会替你执行上述 tap-dance；不要把普通层轻拍双击和清配对操作混为一谈。

$、触板 tap-dance 的窗口是 **400ms，从首击按下起算，不是从松开起算**；第二次按下即选择双击项。已超时或被其他键打断时，单击项可能已经执行。按住 $ 到超时也可能进 bootloader，**没有额外长按安全锁**。

切 BLE 优先用 aA + Q。清当前槽仅在确实要重新配对时使用，并准备在主机端处理旧配对记录；不把清配对、settings_reset 或擦整片闪存当成常规排错步骤。

## 19 更新固件与安全回退

### 手动刷写

1. 核对硬件为 **9981 Pro / bbp9981**，固件不能与 Air 或其他型号混用。
2. 保留当前可回退的 UF2 和 SHA-256。先确认有可靠的引导 / 回退路径；本书不猜实体复位键位置，也不要求拆机。
3. 用 USB **数据线**连接能挂载 UF2 磁盘的电脑，再通过已确认的引导入口进入 bootloader。
4. 将核对好的 UF2 复制到出现的刷机磁盘。无需改名，识别依据是内部格式与目标信息。
5. 等复制完成和设备自动重启；磁盘消失常属正常。不要复制中断电或拔线。

蓝牙不会提供 UF2 磁盘。进入 bootloader 不等于已经写入固件；下载完成、构建成功、刷入、实机确认是四个阶段。更新后逐项检查普通键、机械点击、组合键、两套灯，再按需三击开启轻拍。

### 版本与回退

不含手柄的新迟滞键鼠基线（功能源 `28f6c86`）可作本轮精确回退，其 UF2 SHA-256 为 `e0c20d4dc2d35d5fe6395e4574ad7bb4272d92d3269b6452af95e2d87dcbb94d`。它不是 Xbox 版；新 UF2 校验见第 23 章及[交付记录](<../firmware-delivery/XBOX_CURRENT.md>)。

保留的 ab18d4 精确回退 SHA-256 为 `ab18d4b5c651a6c97d74cc99ef44a24e296810dc1826cce7e29560d83e5a3606`。它保留当时其他功能，但轻拍是另一套判据；不是本版参数的同名备份。

**旧 GBA 功能快照 `abe65ea`、含文档提交 `89fbe9d` 已撤回，仅留本地历史。** 它们未发布，不是可刷当前 Xbox，也不能把旧 GBA 文档或基线 UF2 改名当作 Xbox 交付。

v2.2.4 源码已依本轮授权推送；Actions Run 39428313318 的 ARM 构建、UF2 边界校验与归档成功，细节见第 23 章。设备操作未授权。**未刷写、清配对、擦设置或修改主机配置。** 普通应用 UF2 不等于 settings_reset；维护工具或 AI 不能擅自操作设备。

| 现象 | 优先检查 |
| --- | --- |

## 21 排错：轻拍、滚轮、灯和连接

| 现象 | 优先检查 |
| --- | --- |
| 重启后轻拍失效 | 默认 OFF；普通层重新快速三击左肩，松手后等约 1 秒 |
| 三击后不确定开没开 | 没有专属状态灯；三击可能受按住太久、间隔、移动或切层打断 |

| 调暗后一断电没保持 | 两盏分别调一次，等约 1 秒再关；核对固件版本，别拿动画低点当设定丢失 |
| 插线仍向蓝牙输出 | 查当前槽、连接就绪和输出偏好，选槽与选传输不同 |
| 蓝牙无字 / 无指针 | 选对已连接槽；aA+Q 只选 BLE 偏好，不会凭空建立连接 |

误点影响操作时先三击关闭轻拍，使用机械点击；需要回退由用户自行决定，不因排错自动清设置或重刷。

## 22 Studio 改键与固件默认的区别

**本固件启用 ZMK Studio，且关闭了 Studio 锁定。** 没有额外配置“解锁组合键”，不要去试重启或清配对来解锁。可从 [ZMK Studio](<https://zmk.studio/>)的受支持连接入口连接；具体浏览器 / 客户端和串口权限以当前主机支持为准。

优先用 USB 数据线，在工具里选择 Studio 的 RPC 接口；固件还存在单独的 debug 日志 CDC，**日志口不是 Studio RPC 口**。看不到兼容设备时先排查数据线、枚举、接口和已有占用，不为此自动清设置、重刷或改系统权限。

### 只想看键位，和真正改键，分开做

- 查看默认键图以本书和源码为准；查看已保存自定义要读取当前设备的 Studio 状态。
- 真要修改前，保留原布局 / 导出记录，核对层号和物理位置，只改明确需要的位置。
- 保存到设备的改键可能覆盖编译默认值；**普通应用 UF2 重刷不等于清除 Studio 设置**。
- 改动后逐层验证关键键、返回出口、鼠标与维护键，再更新说明书。

### 这些附加行为不只存在于键图

物理位置 P37 的减速、P41 的按住滚动 / 双击锁轮和 UPPER 固定、P40+P41 的双顺序 Ctrl，都由驱动监听位置实现。仅把键帽对应绑定改成另一功能，**不会自动删除这些监听行为**；层键本身的原操作也不会被组合 Ctrl 全部吞掉。

MEDIA 的 None 不删除监听；GP 独占 / 晚发送门阻断鼠标、滚轮、轻拍，P37 非摇杆加速。P35($) / P40(SYM) / P41(右aA) 回 DEFAULT 后恢复鼠标；重排键位须同时审查驱动。

**MEDIA 全空或仍为旧 J/K＝B/A？** 读取 Studio 保存布局并保留导出，对照第 17 章 19绑定 / 3出口 / 20None；核对黑莓模式、S/K 与机械点击捕获。不要清设置、刷 settings_reset 或清配对。

本书按章定位；PDF / Word 实际分页与键图仍须导出 QA。

## 24 手柄连接与应用兼容边界

**Xbox 仅指布局，非原生 XInput，不冒充微软 VID/PID。** 安卓等系统可能将键鼠与手柄显示为同一设备，无需独立 Xbox 名称。退出 MEDIA 只归中 / 松键，不移除接口；USB / BT 枚举尚未实测。

| 连接 | 本轮做法与检查 |
| --- | --- |
| USB | 保留 HID_0 键鼠，独立 non-Boot HID_1；ID4＋body9＝10 bytes，用数据线 |
| BLE | HOG 尾部独立 Input / CCC / Ref；body9 无 ID，仍为同一蓝牙身份 |
| 输出选择 | 仅向所选端点发游戏输入；先退 MEDIA 再切槽 / 传输 |
| 升级 / 缓存 | 先重连并核对固件 / Studio，不自动清配对 |

在 App 选“手柄 / Controller”按第 17 章分配，勿用字母键盘映射。

| 应用 / 平台 | 各版本均待实机验证 |
| --- | --- |
| 安卓模拟器 | 检测按钮 / 帽 / 轴并分配，不泛称全部支持 |
| Moonlight | 客户端接收 / 映射与远端虚拟手柄分别实测 |
| 盖世游戏 | 系统识别、应用、兼容桥接、具体游戏逐项实测 |
| Droidsteam | 平台 / 版本未确认，不偷换其他 App 承诺 |
| Windows XInput-only / Xbox 主机 | 非 XInput，不保证可用，不擅改用户所选协议 |

LT/RT 仅 0/255，非半按；无连发 / 振动 / Share。Guide 可能被系统 / 客户端截获，**不保证到远端**。单触板操作见第 26 章，计时 / 隔离见第 27 章。参考：[Moonlight 输入](<https://github.com/moonlight-stream/moonlight-docs/wiki/Setup-Guide#keyboardmousegamepad-input-options>)、[XInput / DirectInput 区分](<https://learn.microsoft.com/en-us/windows/win32/xinput/xinput-and-directinput>)。

## 25 手柄验收与保护限制

**已发布 v2.2.4：全量主机回归、ARM 云构建与 UF2 校验 PASS（Run 39428313318）；其 UF2 不含 v2.2.5 方向逻辑。** v2.2.5 仍是本地未构建候选；勿刷上一版 S=↓、Z/K 空的 UF2 或 v2.2.2 未构建候选。本轮未刷写、未清配对或擦设置。

1. 普通层复查字母、鼠标、Cmd/Ctrl、滚轮、轻拍、灯和 Studio；排除接口 / 缓存影响。
2. 检测 13 真实按钮、帽、四轴与 LT/RT；填充按钮不应出现，扳机只发 0/255。
3. 按第 17 章核对 19绑定 / 3出口 / 20None、斜向 / 相反方向及不发字母；Guide 截获另判。
4. 按第 26–27 章测切杆、D/K 的 L3/R3、触板点击与空格的 Guide、持续 / 静止 / 噪声 / 故障；清轴不代替按钮 UP。
5. 游戏层不发鼠标 / 滚轮 / 轻拍；三出口均恢复原路径、旧候选不补发、开关值不改。
6. 持键 / 扳机并滑动，退出、切 USB/BLE、换槽、重连应 neutral，不重播旧按住状态。
7. **实测移动＋黑莓 modifier＋开火等三键**，再逐 App 实玩；Moonlight 核对远端手柄。

### 不能省略的限制

- **矩阵三键鬼键风险未变。** 无二极管 / 部分二极管模型仍有风险；移动＋modifier＋开火、方向＋面键＋肩须实测，串键 / 误退层即停用并反馈组合。
- 新主机先 neutral；未连接 / 未订阅 / 队满 / 过期会清旧状态，须松开重按。旧目标最多重试 400ms，等待期间新主机首键可能过期，不保证零丢键。
- 入退出 / 路由变化取消旧队列，向仍连接的**原目标**尝试 UP；断线 / 拒绝 / 重试耗尽不保证收到。已进入 SDK / 无线队列的包不能撤回；neutral 非 host ACK，不保证绝不卡键。
- USB 持久缓冲 / nRF 忙状态门仅适用本板固定 SDK，不代表原键鼠 DMA 全面修复；复位 / abort、真实 RTOS / 设备仍待验，不靠重启 USB 或擦设置排错。

仅有键盘？先查版本、MEDIA、线缆、槽与缓存；重配由用户决定，**不清全部配对**。

## 26 触板 velocity 虚拟摇杆

### 只有相对位移，不是实体杆或可靠触摸检测

触板提供相对光学位移，没有可靠的触摸 / 抬指状态。本版只用**当前 raw 方向和速度**推算杆偏转，不累计成可锁定的虚拟位置；raw 向右为正、向下为正，与原鼠标坐标一致。它不是“手指放哪里，杆就一直倾向哪里”。

默认触板滑动控制左杆 X/Y；E/X/S/F 为独立 D-pad，D/K 为 L3/R3；触板机械点击固定为 Guide/Xbox。斜向用方向帽、相反方向相消。**手指停住不能维持实体杆倾斜，持续前进须继续滑动。** 这是用户保留的取舍，不擅改为键盘左杆，也不将“停止运动”当成可靠抬指检测。

### 默认左杆，按住黑莓临时右杆

- 进入 MEDIA 并松开旧键后滑动，驱动左 X/Y；在本层重新按住物理黑莓，再滑动才驱动右 Z/Rz。
- 松开黑莓回默认左杆，**不锁定右杆**。每次模式切换先清旧轴，只用切换后的新样本，不把此前运动搬到另一杆；按钮 / D-pad 不因切杆而换 owner。
- 机械触板按压在 DOWN 时固定输出 Guide/Xbox，不按黑莓模式改为 L3/R3；UP 释放 Guide。Space 键也是 Guide，由独立 owner 维护；D/K 分别输出 L3/R3。
- 只有一个触板，不能同时独立控制左右杆；触板点击是 Guide，不代表摇杆按键。L3/R3 由 D/K 独立控制，不把软件报告能力当成已有实体控制器。

计时、参数与鼠标隔离见第 27 章。

## 27 虚拟摇杆参数与鼠标隔离

### 当前纯核参数与归零策略

| 项目 | 当前默认 / 解释 |
| --- | --- |
| raw 增益 | 每分量 ×8，不沿用鼠标 1.2 / 0.6 增益 |
| 逻辑死区 | ±4（含边界）归零；逻辑轴单位，非 raw 接触阈值 |
| 限幅 | 每分量 clamp `[-127,127]` |
| 平滑 | 75% 新＋25% 旧，对称舍入；反向先清该轴旧分量 |
| 最大同向输入 | 从归中起依次 ±95、±119、±125、±127；**首帧不满杆** |
| 有效运动 | 即使值未变也刷新计时；零 / 死区噪声不刷新 |
| 本地 quiet | 末次有效位移后 120ms 清轴，非 host ACK / 到达时限 |
| GPIO / I2C 故障 | 立即清虚拟轴，**不代替按钮 UP**；按原 owner 释放 |

120ms 与轻拍静止确认并非同一状态机；背压、未订阅、断线或 SDK 排队可能延后 neutral。完整主机回归已 PASS，未证明真实 RTOS 定时或主机在 120ms 内归中。

### 游戏层不并发鼠标，退出恢复原路径

MEDIA raw 只供虚拟杆；driver 独占＋晚发送门阻断鼠标 / 滚轮 / 轻拍。P37 slow、P41 滚轮监听保留，P37 非摇杆加速；P35($) / P40(SYM) / P41(右aA) 回 DEFAULT 后恢复鼠标。

游戏层仅临时阻断轻拍 / 取消旧候选，原参数、开机 OFF、三击开关及其值不改；入退出 / 路由变化取消旧游戏队列并尝试 neutral。普通操作仍见第 5–8 章。

进入前排队的轻拍按 GP 代际取消，同 poll 进退不复活；必要 UP 保留，已 admitted / SDK 包不承诺撤回。
