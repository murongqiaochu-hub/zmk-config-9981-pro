## 2. 日常键鼠最短步骤

1. **回普通层。** 松开按键；固定 SYM / UPPER 用 SYM 返回，MEDIA 用 **$、SYM 或右下 aA** 返回。不要靠重启、刷机或清配对退层。
2. **选择蓝牙键鼠。** 从普通层按住右下 aA，按通话 / 黑莓 / 顶部返回 / 结束选槽 0 / 1 / 2 / 3，再用右 aA + Q 选择 BLE 输出偏好。槽应与主机连接；选择偏好不等于已经连通，也不自动删除配对。蓝牙是本轮验收目标。
3. **输入和点击。** 普通层字母正常输入；黑莓是左 GUI（Mac / iPad 为 Cmd），左下 aA 为 Ctrl，Z 左侧 alt 键帽实际为 Shift。触板滑动移指针、机械按压为左键；默认左肩 / 右肩为左键 / 右键，翻转模式下肩键角色互换。
4. **滚动和方向。** 按住右 aA 滑触板临时滚动；进入 aA 层后快双击右 aA 锁轮，再双击解锁。锁轮初始 0°，解锁 / 重锁回正；SYM 仅退层，不清锁轮。松开 aA 且锁轮时，黑莓三击选“左→上、右→下、上→右、下→左”，顶部返回三击选相反固定档；同键重复不累加。按住 aA 时黑莓 / 返回优先选槽 1 / 2，不选方向。
5. **速度、翻转和灯。** 右 aA + Z 每次按下循环 `0.6 → 0.9 → 1.2 → 1.5 → 1.8 → 0.6`，首次 1.2，最后一次调节后等至少 1 秒再断电。按住右 aA 双击 M 切换鼠标 Y 翻转与普通层肩键角色，重启关闭。键盘灯用右 aA + X / N 减 / 加、V 开关；触板灯用 C / B 减 / 加，两套亮度分别保存。
6. **轻拍按需开启。** 开机默认关闭。在普通层对当前左键角色肩键快速完整三击（默认左肩，翻转时右肩），松手后等约 1 秒再试；误触时同样三击关闭，改用机械点击。本轮不调轻拍参数。

三击每拍按住不超过 180ms、释放至下一次按下不超过 220ms；aA 锁轮双击每拍小于 450ms、间隔不超过 350ms。翻转组合也是 180/220ms；夹其他键取消未完成序列。完整步骤、组合输入与危险维护键见[使用说明书](<9981Pro_使用说明书.md>)。

**避免误触维护入口：** UPPER 的 R 会重启，触板机械快双击会清当前蓝牙槽，$ 单击会进 bootloader。选 BLE 用右 aA + Q，不用危险的 $ 双击来碰运气。本文是操作说明，不授权代为刷写、清配对、擦 settings 或修改主机。

## 6. 验证与仍有的限制

- 源码范围核对、当前源码 host 回归、真实 ARM / ELF / UF2 校验、交付、用户刷入和蓝牙实机验收必须分别记录；本文件第1节未填项不得标为通过。冻结旧回归仅提供历史对照。
- 本轮只以蓝牙键盘和鼠标为用户验收目标；用户取得并自行确认刷入本版后，只需最短核对：**BLE普通字母输入、BLE指针移动与一次机械点击、MEDIA明确出口返回普通层后仍可输入/点击**。第2节其余操作是日常查阅，不是新增长测任务；不要求再刷旧手柄版。USB 或软件模拟通过不能替代蓝牙结果，没有实机证据时不承诺“稳定版”“所有平台可用”“无线已恢复”。
- 删除尾部手柄服务会改变主机看见的接口 / 服务布局及GATT hash；保留身份和配对数据，不等于保证所有旧主机缓存无影响。不能据此自动清配对、擦 settings 或改主机。
- 既有原生 HID_0 可变报文 DMA、abort 丢 ready / 许可等限制不因去手柄自动解决；RAM 安全不等于主机 ACK。已交给 SDK 的包不能保证撤回。
- 轻拍仍是运动启发式，细小搓动可误点；矩阵多键风险、主机加速和 App 快捷键差异仍需分别看待，不新增调参或重构来模糊收口范围。
- 回退由用户决定。旧 GBA / Xbox、安卓最后候选的源和产物只保留历史，不重新发布、不继续手柄研发，也不把历史成功或失败搬成本版实测结论。
